Тренажёр теории ПДД Армении (категории A, B, C, русский язык)
==============================================================

Вопросы — официальные билеты roadpolice.am (1050 вопросов, 10 групп).
Режимы: экзамен, тренировка по группам, список ошибок, статистика.
К большинству вопросов есть пояснения со ссылкой на пункт правил.

Работает на вашем компьютере, интернет не нужен. Ничего устанавливать
не надо: внутри уже готовые программы.


КАК ЗАПУСТИТЬ
-------------

Сначала распакуйте архив целиком в любую папку
(запускать прямо из архива нельзя).

Windows
  Дважды щёлкните start-windows.bat.
  Если Windows покажет «Система Windows защитила ваш компьютер» —
  нажмите «Подробнее» → «Выполнить в любом случае».
  Откроется чёрное окно и через пару секунд браузер с тренажёром.

macOS
  Дважды щёлкните start-mac.command.
  Если macOS пишет, что программу нельзя открыть, потому что
  разработчик не подтверждён, — один раз выполните в Терминале
  (перетащите папку в окно Терминала вместо <папка>):
      xattr -dr com.apple.quarantine <папка>
  и снова дважды щёлкните start-mac.command.

Linux
  В терминале, в папке тренажёра:  ./start-linux.sh

Если браузер не открылся сам, откройте адрес:  http://127.0.0.1:8087


КАК ОСТАНОВИТЬ
--------------

Закройте окно, которое открылось при запуске (или нажмите в нём Ctrl+C).
Пока окно открыто, тренажёр работает.


ГДЕ ХРАНИТСЯ ПРОГРЕСС
---------------------

В папке data/ рядом со скриптами (файл trainer.db). Чтобы начать
заново — удалите папку data/, пока тренажёр остановлен. Чтобы перенести
прогресс на другой компьютер — скопируйте её.

Тренажёр доступен только с этого компьютера. Телефоны и другие устройства
в сети к нему не подключатся.


ЕСЛИ НЕ ЗАПУСКАЕТСЯ
-------------------

«address already in use» / «Обычно разрешается только одно использование
адреса» — тренажёр уже запущен (в другом окне) или порт 8087 занят
другой программой. Закройте лишнее окно, или замените 8087 на другой
номер в скрипте запуска (в двух местах).
